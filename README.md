# Waydroid-ATV-autoinstall
The Waydroid installation is too difficult? The built-in Android 13 version is too old? Here's the solution!

## Features
The program can install Waydroid (the main program) automatically and install LineageOS 24.0 (Android 17, built by Waydroid-ATV).

## System requirements
- Wayland session enabled
- Debian 13+ or Ubuntu 26.10+
  or system based on them

## Download & Install
1. Download the latest version from the Releases page
2. Open a new terminal window
3. Locate to the program's path
4. run ./installWaydroidA17
5. Follow the instructions
