# Still having problems

If you're sill having problem after [reinstalling waydroid](reinstalling-waydroid.md), please follow the following instructions.

### 1. Make sure your hardware/software are supported

Make sure your PC is supported. For the requirements, read the [System requirements](../getting-started/system-requirements.md) page.

### 2. Fix the problem by following the Waydroid's documents

Sometimes, problems need to solved by some complicated operation. If you think that you can, try following the [Waydroid offical documents](https://docs.waydro.id/debugging/troubleshooting).
