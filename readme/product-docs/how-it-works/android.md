# Android

Thanks to the [Waydroid](https://github.com/waydroid/waydroid) repository, we can now run Android system and apps in Linux!&#x20;

Waydroid uses Linux namespaces (user, pid, uts, net, mount, ipc) to run a full Android system in a container and provide Android applications on any GNU/Linux-based platform.

The Android system inside the container has direct access to any needed hardware.

The Android runtime environment ships with customized Android system image based on [LineageOS](https://lineageos.org/).
