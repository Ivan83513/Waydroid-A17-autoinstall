# Waydroid-A17-autoinstall
The Waydroid installation is too difficult? The built-in Android 13 version is too old? Here's the solution!

## Features
The program can install Waydroid (the main program) automatically and install LineageOS 24.0 (Android 17, built by Waydroid-ATV) for users.

To getting started, please [README](https://ivan83513.gitbook.io/waydroid-a17-autoinstall/) first.
