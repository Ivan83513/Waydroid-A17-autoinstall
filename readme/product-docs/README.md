# Welcome

Waydroid-A17-autoinstall can automatically help you to set up your Waydroid environment.

* It can automatically install Waydroid for you
* It can help you to install LineageOS 24.0 (Android 17, built by Waydroid-ATV)
* If you have any problem, use the uninstall tool to remove Waydroid
