# Reinstalling Waydroid

### Uninstall Waydroid

To uninstall Waydroid, you can also use the `setup` program which can download from the [Releases](https://github.com/Ivan83513/Waydroid-A17-autoinstall/releases) page.

{% hint style="danger" %}
Uninstalling Waydroid will delete all the data stored in Android. Please backup the data if they are important.
{% endhint %}

To run the program, you just need to locate to the path of the program via your file manager, right-click in a empty place, and then select the "Open in terminal" option.

Run the program by entering:

```bash
./setup
```

{% hint style="info" %}
This program is only supported for Debian-based Linux distros (Ubuntu, Debian...)
{% endhint %}

### Install Waydroid and Android 17 again

To install Waydroid again, please follow the "[Download](../getting-started/download.md)" and "[Install](../getting-started/install.md)" page.
